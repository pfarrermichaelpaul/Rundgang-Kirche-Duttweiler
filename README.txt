Wichtig zur Bildqualität:
Die fünf JPG-Dateien im Ordner "panoramas" sind unveränderte Kopien der
hochgeladenen Originaldateien. Sie wurden nicht verkleinert, neu gespeichert
oder nachkomprimiert.

Empore:
Die JPG-Datei wurde NICHT gedreht. Der Startblick wird ausschließlich im
Panorama-Code auf den Altar ausgerichtet. Dadurch bleibt die Originalqualität
vollständig erhalten.

Veröffentlichung auf GitHub Pages:
Den INHALT dieses Ordners in das Repository für den Duttweiler-Rundgang laden.
GitHub Pages anschließend wie bei den bestehenden Rundgängen aktivieren.

Hinweis:
Pannellum wird über jsDelivr geladen. Für den Rundgang ist daher eine
Internetverbindung erforderlich – auf GitHub Pages ist das normalerweise
unproblematisch.
